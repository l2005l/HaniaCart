# HaniaCart

רשימת קניות משותפת לכל הבית, מלאי עם התראות תפוגה, סריקת חשבוניות, תכנון ארוחות ומעקב מחירים. בלי הרשמה: כל בית מקבל מפתח, ושולחים לבני הבית קישור הצטרפות.

- `public/index.html` האפליקציה, עמוד אחד בלי שלב בנייה.
- `src/worker.js` השרת: Cloudflare Worker עם מסד D1.
- `src/push.js` התראות בוקר (Web Push בלי תוכן, כמו ב-HaniaGo).
- `migrations/` מבנה המסד.
- `tests/` בדיקות השרת. הרצה: `npm test` (Node 22).

## מה יש באפליקציה

| לשונית | מה עושים בה |
| --- | --- |
| מלאי | חיפוש והוספה, מיקומים, תאריכי תפוגה (משוערים או מצילום האריזה), "נפתח", מוצרי בסיס עם כמות מינימום, "נגמר" ו"נזרק" עם ביטול |
| קניות | רשימה משותפת לפי מחלקות, הדבקת רשימה שלמה מוואטסאפ, הצעות לפי היסטוריית קניות, "קונים הרבה", מוצרי בסיס שחסרים, שליחה בוואטסאפ |
| ארוחות | תוכנית ארוחות ממה שיש בבית, קודם מה שעומד לפוג, והחסרים לרשימה בלחיצה |
| סריקה | צילום חשבונית (מוצרים, מחירים, רשת וסכום) או צילום מקרר |
| סיכום | הוצאות לפי חודש, מה התייקר, איפה זול יותר, היסטוריית מחיר לכל מוצר, מדד בזבוז |

שיתוף מאפליקציה אחרת (למשל הודעת וואטסאפ עם רשימה) ל-HaniaCart המותקנת באנדרואיד מוסיף את השורות לרשימה.

## פריסה

כל דחיפה ל-`main` מריצה בדיקות ואז פורסת ל-Cloudflare. הפריסה יוצרת את מסד הנתונים `haniacart` אם הוא לא קיים.

צריך להגדיר פעם אחת ב-GitHub, תחת Settings, Secrets and variables, Actions (אותם ערכים כמו ב-HaniaGo):

| סוד | מאיפה |
| --- | --- |
| `CLOUDFLARE_API_TOKEN` | Cloudflare, My Profile, API Tokens. הרשאות עריכה ל-Workers Scripts, ל-D1 ול-Workers AI |
| `CLOUDFLARE_ACCOUNT_ID` | מופיע בעמוד Workers בחשבון |

אחרי הפריסה הראשונה מוסיפים דומיין ב-Cloudflare: ה-Worker `haniacart`, Settings, Domains and Routes, `cart.hania360.com`.

## זיהוי תמונות וארוחות

| סוד | מה הוא מפעיל | בלעדיו |
| --- | --- | --- |
| `ANTHROPIC_KEY` | Claude קורא חשבוניות בעברית, מקרר ותאריכי תפוגה, ומתכנן ארוחות. עלות של בערך כמה אגורות לסריקה | Workers AI של Cloudflare (חינמי במכסה, פחות מדויק בעברית) |

מגדירים ב-Cloudflare, ב-Worker, תחת Settings, Variables and Secrets, כסוד. `CLAUDE_MODEL` ב-`wrangler.jsonc` קובע את המודל.

מגבלות: `AI_DAILY_CAP` (400 פניות למודל ביום לכל השירות), `HH_DAILY_SCANS` (40 סריקות ביום לבית), 20 תכנוני ארוחות ביום לבית.

## פרטיות

אין חשבונות ואין שמות מלבד השם שכל אחד בוחר להציג ליד מה שהוסיף. מי שמחזיק בקישור ההצטרפות רואה ועורך את הבית, לכן שולחים אותו רק לבני הבית. רשומות שנמחקו נשכחות אחרי 60 יום, קניות אחרי שנתיים, ובית שלא נפתח 400 יום נמחק.
